# BURMOLDA OS

**Fan-made Arch Linux remix · v0.1.0 · x86_64 · Meme Edition**

BURMOLDA OS is a dark, neon, meme-heavy KDE Plasma live desktop built on Arch Linux and Archiso. This repository contains the ISO profile customizer, a first-boot live-session setup, GRUB styling, original wallpapers generated during build, and an offline soundboard with synthesized sound effects.

> Development snapshot. The first ISO build must be tested in a virtual machine before use on real hardware. The installer opens Archinstall; it is a guided terminal installer, not Calamares.

## Features

- Official Archiso releng profile as the base.
- GRUB boot menu for UEFI; upstream Syslinux path for legacy BIOS.
- KDE Plasma, SDDM, NetworkManager, PipeWire, Firefox, Dolphin, Discover and common utilities.
- Temporary live user with automatic login.
- Original 1600×900 wallpapers and four synthesized WAV effects generated by a Python standard-library script at build time. No third-party stream recordings or copyrighted music are bundled.
- Desktop shortcuts for Wallpapers, Soundboard and the installer.
- Installer launcher opens Archinstall in Konsole. In Archinstall, choose KDE Plasma as the desktop profile and GRUB as the bootloader.

## Build automatically

The GitHub Actions workflow is triggered by pushes to main and can also be started manually.

1. Open the repository's **Actions** tab.
2. Select **Build BURMOLDA OS ISO**.
3. Choose **Run workflow** and confirm.
4. Open the completed run and download the **burmolda-os-x86_64-iso** artifact.

The artifact contains the ISO and its SHA-256 checksum. GitHub retains the artifact for 7 days.

## Build locally on Arch Linux

Requirements: up-to-date Arch Linux x86_64, internet access, several GB of free disk space, and the packages below.

~~~bash
sudo pacman -Syu --needed archiso grub dosfstools squashfs-tools libisoburn mtools arch-install-scripts python
bash scripts/build-iso.sh
~~~

The output is written to out/.

## Test before installing

1. Boot the ISO in QEMU, VirtualBox or VMware using UEFI.
2. Check GRUB, the KDE live desktop, networking, audio, wallpapers and soundboard.
3. Launch the installer only inside a disposable virtual machine first.
4. Install to a test VM disk and check that GRUB boots successfully.
5. Do not install on a disk containing important data until the live system and installer have been validated.

## Project status and limitations

- The live ISO profile and build workflow are development configuration, not a certified release.
- The current installer is Archinstall's guided TUI. Calamares is not included yet.
- The installed target receives the KDE/GRUB choices made in Archinstall. Applying all Burmolda branding to the installed target is a later milestone; the live-session overlay is not automatically copied into the target installation.
- The GitHub workflow has not yet been validated by a successful run. A successful Actions run and VM test are required before calling the ISO ready.
